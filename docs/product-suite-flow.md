# 商品套图：功能与交互说明

> 对应原型：[product-suite.html](../product-suite.html)。目标用户是需要一次产出多种商品展示图的电商运营与设计人员。

## 1. 目标与输出范围

一个商品任务可以选择多种图片类型及各自数量，逐张生成提示词，确认所需图片后统一出图。输出范围为：白底主图、多角度图、细节图、场景图、卖点图、尺寸参数图、对比图、促销图。**不包含详情长图**；详情长图使用独立页面。

## 2. 页面结构与字段

左侧配置、右侧结果在同一页面。顶部「历史」打开历史抽屉；「批量创建任务」进入批量页面，默认定位到商品主图模式。

| 字段 | 当前规则 |
| --- | --- |
| 商品素材 | 上传图片或从资产库选择；原型上限 16 张；没有“使用示例”入口 |
| 目标电商平台 | 国内与海外平台下拉选择 |
| 目标市场、文案语种 | 独立下拉选择 |
| 清晰度 | 1K、2K、4K |
| 画面比例 | Auto 及多种常见比例，以比例选择而非像素参数 |
| 商品卖点 | 多行文本，可手动编辑或 AI 提取演示内容 |
| 设计风格 | 爆款风格、参考 / 自定义；可填写方向与选择参考图 |
| 输出类型与数量 | 按图片类型勾选，各类型独立增减数量；至少选 1 种 |

尺寸参数图、对比图和促销图只能使用用户已提供的尺寸、对比依据、价格、折扣和期限。缺少相应事实时，应避免编造。

## 3. 单次生成流程

1. 添加商品图并填写平台、市场、语言、清晰度、比例、卖点和风格。
2. 勾选输出类型并为每类设定数量，点击「生成套图方案」。
3. 右侧按**每张图**展示可编辑提示词；用户可单独取消不需要的图片。
4. 点击「生成所选图片」，右侧切换为本次套图结果，支持逐张预览和下载，以及下载全部。
5. 本次任务的字段、商品图、图片类型和数量、提示词与结果预览进入「历史」；每张结果同步到资产库「素材 → AI生成」。

## 4. 历史与下一次生成

历史抽屉仅在用户点击「历史」时出现；它不长期占用右侧工作区。历史详情展示本次设置、原图、各张图片的提示词和结果。点击「以此任务再次生成」会将旧记录复制成新的可编辑任务，旧记录保持不变。

本次生成完成后，右侧提供「新建套图」按钮。点击后清除本次商品图、提示词和结果，保留常用平台、市场等设置；右侧恢复初始示例，用户可上传下一件商品。已经完成的套图仍可从历史查看。

## 5. 状态与验收

| 状态 | 右侧显示 | 主要操作 |
| --- | --- | --- |
| 待配置 | 图片类型示例 | 添加素材、设置类型与数量 |
| 提示词待确认 | 逐张提示词 | 编辑、勾选、生成所选图片 |
| 已完成 | 本次每张成图卡片 | 预览、下载、新建套图 |

- 无商品图、未选择图片类型或未选中提示词时，不得继续生成。
- 生成套图后，历史增加一个任务记录；资产库按实际选中的每张图增加素材项。
- 新建任务不会覆盖已完成记录。
- 从历史复制后，图片类型、数量、风格和文案均应恢复到可编辑状态。

## 6. 原型说明

当前图片和生成动作是演示素材与前端状态，尚未接入真实图像模型、真实下载或服务端云存储。历史使用本机浏览器存储；资产库「AI生成」记录用于演示跨页面流转。

## 开发字段与归档契约

完整枚举、默认值、商品关联 ID、结果同步及删除规则见 [开发字段字典与结果归档规则](https://github.com/aa312557272-bot/fashmaker-prototype/blob/main/docs/developer-field-contract.md)。生成成功时，已引用商品的结果必须同时出现在 AI 生成和该商品详情素材区。


## 自定义模型与导航修订（2026-11-10）

移除顶部横向功能快捷导航，保留左侧功能导航。通过左侧「自定义模型」管理配置；窄屏顶部提供同名入口。图片功能只列出图片模型，视频功能只列出视频模型；平台原有选项保留，保存后即加入对应下拉，切换本次模型不要求逐步选择。文字分析、文案、提示词和脚本固定使用 FashMaker 平台模型，不提供文字模型配置。详细字段、演示边界及验收见 [自定义模型配置](custom-models-flow.md)。


### 2026-11-10 布局统一修订

所有页面侧边栏采用 shared-sidebar.js / shared-sidebar.css 的同一结构与样式：216px 宽、FashMaker 品牌与副标题、首页、创作工具、管理、账号区；菜单顺序为视频创作、详情长图、商品套图、商品生视频、爆款复刻、AI 换装、穿搭分离、数字人口播、图文笔记、资产库。仅当前功能高亮变化。批量页也使用同一侧栏。模型管理保留在管理区域；设置按钮打开模型配置，创作记录打开当前功能历史。首页和视频创作暂分别链接现有详情页和商品视频页，不新增独立功能。

模型选择统一放在创作设置末尾、生成提示及按钮前；AI 换装清晰度在模型之前。商品生视频与爆款复刻模型从右侧策划区迁到左侧设置末尾。批量全局和单任务覆盖的模型均为最后参数；图文笔记放在输入框之后、发送操作之前。移动 DOM 保留原 select ID、事件与选择值，文字模型口径和生成规则不变。窄屏仍隐藏主侧栏，保留顶部模型管理入口。
