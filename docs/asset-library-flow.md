# 资产库：功能与交互说明

> 对应原型：[asset-library.html](../asset-library.html)。目标用户是管理商品信息、输入素材与生成作品的电商团队成员。

## 1. 信息架构

顶部一级切换为「素材」与「商品」：商品是一条包含标题、描述、卖点和关联素材的业务对象；素材是可独立查看的图片或视频记录。两者不混作同一个列表。

素材页的二级 Tab 为「AI生成」「上传素材」「数字人」「合成视频」「收藏」。商品页不显示这些素材 Tab。素材与商品列表均可切换网格 / 列表视图。

## 2. 素材页

| 功能 | 交互 |
| --- | --- |
| AI生成 | 展示详情长图、套图、商品生视频及批量任务同步的结果记录；视频项标注为演示封面 |
| 搜索与筛选 | 按名称搜索，按类型筛选 |
| 视图 | 网格与列表之间切换 |
| 批量操作 | 进入选择状态后批量下载或批量删除；不展示生成图片 / 生成视频按钮，也不展示存储量与成员筛选 |
| 单项预览 | 点击素材查看大图或演示封面 |

生成完成时才写入 AI生成，未完成或只生成提示词的任务不写入。素材记录应保留来源功能、来源任务、创建时间及可用预览。删除素材记录不应删除对应的历史任务；真实产品需定义文件引用与删除策略。

## 3. 商品页

商品可采用网格或列表布局。点击商品打开右侧信息抽屉；抽屉包含关联图片 / 视频素材、商品标题、商品描述和逐条卖点。所有文本都可以编辑。商品素材缩略图上的预览、删除按钮在**鼠标移入时**显示，而不是选中后才显示。

「添加商品」采用手动录入：商品名称与至少一张图为必填；描述与卖点选填；图片可以上传或从素材库选择。添加弹窗不显示商品链接解析字段。商品详情中的「AI生成标题、描述和卖点」会填入可继续编辑的演示文案。

「安装 Chrome 扩展」仅保留入口；本期原型不实现安装流程或电商链接采集逻辑。

## 4. 与创作页面的衔接

在商品详情中可选择「详情图」「商品套图」「商品生视频」进入相应创作页面，并传入当前商品信息与素材。单品生成完成后，历史记录保留本次完整字段快照；结果素材同步回「素材 → AI生成」。批量生图也按已完成的商品任务同步结果。

资产库用于查看和复用结果；生成历史用于按任务查看当时的输入、参数、提示词或分镜与结果。这两个入口分别服务于素材管理和任务追溯。

## 5. 状态与验收

- 「素材」和「商品」具有独立列表与筛选；切换后不混淆数据。
- 商品可添加、打开、编辑并保存；缺少名称或商品图时不能提交新增。
- 从商品详情进入三个创作页面时，商品图和已编辑的信息可带入对应配置。
- 每次完成生成后，AI生成 Tab 新增对应素材项；视频结果明确标注演示封面。
- 批量选择后可执行批量下载与删除；删除后列表立即更新。
- 商品缩略图预览 / 删除操作在 hover 时出现。

## 6. 原型说明

当前资产、商品和生成记录主要使用浏览器本地存储与演示数据。真实文件上传、下载、权限隔离、云同步、容量统计及 Chrome 扩展采集尚未接入；视频素材仅展示演示封面，不应误认作可播放成片。

## 开发字段与归档契约

完整枚举、默认值、商品关联 ID、结果同步及删除规则见 [开发字段字典与结果归档规则](https://github.com/aa312557272-bot/fashmaker-prototype/blob/main/docs/developer-field-contract.md)。生成成功时，已引用商品的结果必须同时出现在 AI 生成和该商品详情素材区。
