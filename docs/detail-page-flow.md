# 商品详情长图：功能与交互说明

> 对应原型：[index.html](../index.html)。文档描述当前确认的产品流程，并标明原型模拟行为。目标用户是需要为单个商品快速制作电商详情页的运营与设计人员。

## 1. 目标与边界

上传或从资产库选择商品图后，用户配置平台、市场、文案语种、清晰度、画面比例、商品卖点和视觉风格。系统先输出可编辑的完整长图提示词，用户选定一套后生成**一张连续的详情长图**。不拆成多个详情模块，也不输出多张分段长图。

## 2. 页面区域

| 区域 | 内容 | 作用 |
| --- | --- | --- |
| 左侧配置 | 商品素材、平台、市场、语种、清晰度、比例、卖点、风格 | 编辑本次任务输入 |
| 右侧工作区 | 示例、提示词候选、本次生成结果 | 随任务阶段切换 |
| 顶部历史 | 历史任务抽屉 | 查看既往任务及其完整快照 |
| 结果区 | 长图预览、下载、新建详情图 | 完成本次任务并开始下一次 |

## 3. 输入字段与规则

| 字段 | 规则 |
| --- | --- |
| 商品素材 | 上传 JPG、PNG、WEBP，或从资产库选择；原型上限 16 张；至少 1 张才能继续 |
| 目标电商平台 | 包含淘宝、天猫、京东、拼多多、抖音电商、1688，以及 TikTok Shop、Amazon、Shopee、Lazada、Temu、AliExpress、Shopify |
| 目标市场 | 按北美、欧洲、亚洲、中东分组；与文案语种分别选择 |
| 文案语种 | 从语种下拉框选择；用于提示词中的画面文案要求 |
| 清晰度 | 1K、2K、4K，下拉选择 |
| 画面比例 | Auto、常见横竖比及 1:3 等比例，下拉选择；作用于整张长图 |
| 核心卖点 | 多行文本；可手动编辑，也可点击“一键解析”或“AI 生成”填入演示文案 |
| 详情页风格 | 爆款风格或参考 / 自定义；自定义模式填写视觉方向 |
| 内容组织 | 固定为单张连续画布，阅读路径为主视觉 → 卖点与细节 → 使用场景 → 收尾信息 |

不得凭空补充未提供的参数、认证、功效、价格或质保信息。

## 4. 单次生成流程

1. 用户添加至少一张商品图，并检查商品卖点与目标设置。
2. 点击「生成长图提示词」。右侧显示多套**完整长图**候选，每套对应一张长图；候选文本可编辑。
3. 用户单选一套提示词，点击「生成所选长图」。未选中时生成按钮不可用。
4. 右侧进入生成中状态，完成后直接展示本次长图结果，可预览或下载。
5. 本次输入、素材、所选提示词和结果预览保存到顶部「历史」；结果同时同步到资产库的「素材 → AI生成」。

## 5. 历史与再次生成

历史只在点击顶部「历史」后以右侧抽屉出现，不常驻工作区。列表按时间倒序展示；进入一条记录可查看当次字段、原始商品图、提示词及结果预览。关闭抽屉返回当前页面。

生成完成后，结果区提供「新建详情图」：清空本次商品图和结果，保留平台、市场、语种等常用设置作为下一任务的起点。历史详情提供「以此任务再次生成」：复制该记录的字段和素材到**新任务配置**，允许修改后重新生成；旧记录不被覆盖。

## 6. 关键状态与验收

| 状态 | 用户看到的内容 | 可执行操作 |
| --- | --- | --- |
| 待配置 | 右侧示例 | 上传 / 选择素材、修改设置 |
| 提示词待确认 | 可编辑的候选提示词 | 单选、修改、生成 |
| 生成中 | 本次任务的处理中提示 | 等待结果 |
| 已完成 | 一张长图结果 | 预览、下载、新建任务、查看历史 |

- 没有商品图时，不能提交提示词生成。
- 未选择提示词时，不能开始出图。
- 完成一次生成后，历史新增一条任务记录，资产库新增一项 AI 生成素材。
- 点击「新建详情图」后，右侧回到初始状态，可继续创建下一次任务。
- 历史详情的「以此任务再次生成」应恢复当次参数，而不是修改旧任务。

## 7. 原型说明

当前页面使用预设文本和图片模拟 AI 生成；下载按钮展示交互，不代表已有真实可下载的长图文件。历史快照保存在本机浏览器存储中，资产库同步也是本地演示数据；跨设备云同步和真实模型生成需要后端接入。
