# 自定义图片与视频模型

版本 v1.0，2026-11-10。统一口径见 [字段契约第 11 节](developer-field-contract.md#11-自定义图片--视频模型2026-11-10)。

## 入口与流程

所有页面取消顶部横向功能快捷导航，保留左侧导航。左侧新增「自定义模型」按钮，窄屏顶部也有入口。弹窗展示已有配置和添加表单；填写用途、名称、协议、完整接口地址、API Key、模型 ID。检查配置格式不发送网络请求。保存后留在弹窗，显示成功反馈；关闭后可从对应功能模型下拉选择。支持编辑和确认删除。取消或 Esc 关闭不提交未保存表单。

图片：详情长图、商品套图、批量全局及单任务覆盖、AI 换装/改姿势/多模特/多商品、穿搭分离、图文笔记。视频：商品生视频、爆款复刻、数字人口播。文字分析、商品文案、提示词、脚本继续使用平台模型，无客户配置入口。数字人人物参考图仍沿用原有演示，不将视频配置用于人物生图。

## 数据与边界

配置 ID 稳定，选择值为配置 ID，显示名称带「自定义」。已有平台选项保留，保存配置不自动切换当前任务。配置元数据本机持久化，Key 只在当前标签页会话存储；新标签页或会话缺 Key 时在配置列表提示重新填写。仅可用测试 Key，不宣称生产级加密。

各创作历史保存所选模型元数据，不保存 Key；详情长图、套图、视频等原有历史字段继续保存下拉值，新增页面另存 modelConfig；图文笔记只在结果版本上保存模型元数据，仍不保存输入或对话。批量全局和单任务覆盖使用相同选项，已有覆盖值与生成时配置同时保留。历史复制不覆盖旧记录；已删除配置的历史名称可回看，真实服务接入前需重新校验有效配置。

当前仅演示配置与选择，不调用接口，不验证连通性或额度，也不根据模型改变演示成图和视频。视频上传、轮询、结果下载以及供应商参数适配均待后端实现。本次未改变生成提示词或素材处理规则，原有各功能提示词文档继续适用。

## 验收

1. 全部页面无顶部横向快捷导航，模型配置入口可打开、关闭、Esc 退出。
2. 添加图片/视频配置后，仅进入对应类型功能下拉；刷新、跨页面保留元数据。
3. 批量单任务覆盖可选择与全局相同的自定义模型。
4. 必填、地址、用途与协议校验有效，保存失败明确显示错误。
5. 编辑稳定 ID 不变，删除需确认，旧历史和资产不被删除。
6. Key 不进入 localStorage、历史、结果资产；检查配置不发起网络请求。
7. 桌面和 390px 窄屏弹窗无横向溢出，所有字段和操作可滚动访问。

与旧原型差异：原无模型下拉的详情、套图、穿搭分离、数字人口播与图文笔记新增下拉；原有模型枚举增加客户配置选项。顶部导航从共享脚本中删除，不隐藏左侧功能入口。

预览修订：本地 JS/CSS 资源增加版本号，避免浏览器沿用旧版共享导航脚本；当前目录预览可使用禁用缓存的独立服务，与旧副本服务分开。


### 2026-11-10 布局统一修订

所有页面侧边栏采用 shared-sidebar.js / shared-sidebar.css 的同一结构与样式：216px 宽、FashMaker 品牌与副标题、首页、创作工具、管理、账号区；菜单顺序为视频创作、详情长图、商品套图、商品生视频、爆款复刻、AI 换装、穿搭分离、数字人口播、图文笔记、资产库。仅当前功能高亮变化。批量页也使用同一侧栏。模型管理保留在管理区域；设置按钮打开模型配置，创作记录打开当前功能历史。首页和视频创作暂分别链接现有详情页和商品视频页，不新增独立功能。

模型选择统一放在创作设置末尾、生成提示及按钮前；AI 换装清晰度在模型之前。商品生视频与爆款复刻模型从右侧策划区迁到左侧设置末尾。批量全局和单任务覆盖的模型均为最后参数；图文笔记放在输入框之后、发送操作之前。移动 DOM 保留原 select ID、事件与选择值，文字模型口径和生成规则不变。窄屏仍隐藏主侧栏，保留顶部模型管理入口。


## 自定义模型正式开发交付（v1.0）

[完整开发规格](custom-models-development.md)定义正式服务的全部配置字段、条件校验、空间权限、适配协议、HTTP接口、任务状态、幂等重试、密钥管理、结果归档及M01–M30验收。配套[JSON Schema](contracts/custom-model-config.schema.json)可供后端和测试使用。

本页此前的localStorage/sessionStorage、image-api/video-task和格式检查属于当前静态原型；正式开发采用规格中的服务端安全存储、image-api-v1/video-gateway-v1及真实测试契约。此次只交付开发文档，HTML并未因此获得真实模型调用、空间默认、能力检测或线上存储。既有商品与任务规则继续适用；具体接入行为以新规格为准。
