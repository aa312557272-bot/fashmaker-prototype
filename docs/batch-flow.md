# 批量生图：功能与交互说明

> 对应原型：[batch.html](../batch.html)。入口仅在[详情长图](../index.html)与[商品套图](../product-suite.html)的「批量创建任务」；不作为独立主导航 Tab。目标用户是一次处理多个商品的运营人员。

## 1. 任务类型与流程

页面在「主图」和「详情图」间切换。用户先设置全局参数，再创建每个商品任务，至少 3 个任务、且每个任务至少有一张商品图，才可提交。批量流程为：**全局设置 → 商品任务 → 生成批量方案 → 二次确认 → 直接生图 → 查看进度与结果**。批量模式不逐条展示或确认提示词。

## 2. 全局批量设置

| 字段 | 说明 |
| --- | --- |
| 目标平台 | 智能匹配或指定国内 / 海外电商平台 |
| 目标市场、目标语言 | 分别设置；语言可选无文字（纯视觉） |
| 模型 | Nano Banana 2、GPT Image 2.5、Flux Kontext 等演示选项 |
| 尺寸比例、清晰度 | 比例下拉与 1K / 2K / 4K 下拉 |
| 主图模块 | 智能模块或自定义模块；遵循单商品套图的图片类型规则 |
| 详情图生成数量 | 只在详情图模式出现；主图模式没有「每个任务生成数量」字段 |

全局参数默认应用到所有任务；每个商品任务可通过「单独设置」覆盖部分参数，并可恢复为跟随全局。详情图模式不展示详情图结构、自定义要求或独立视觉风格全局字段。

## 3. 单个商品任务

内容顺序固定：**上传 / 从资产库选择商品图 → 商品卖点 → 设计风格 → 是否覆盖全局参数**。

| 内容 | 规则 |
| --- | --- |
| 商品图 | 每任务最多 6 张，可上传或从资产库选；至少 1 张 |
| 商品卖点 | 每个任务独立文本框，并有独立「AI帮写」按钮 |
| 设计风格 | 每个任务独立选择推荐风格或填写自定义风格 |
| 覆盖全局 | 单任务覆盖平台、市场、语言、模型、比例、清晰度等；详情图模式还可覆盖生成数量 |
| 新建 / 删除 / 折叠 | 「新建商品任务」增加任务；各任务可以删除和折叠 |

## 4. 提交、原页面与下一批

点击「生成批量方案」时检查任务数和商品图；通过后弹出二次确认。确认后直接进入生图：编辑表单让位于提交状态页，显示批次名称、整体进度、每个商品任务的状态和结果缩略图。任务运行进度同步显示在「生图历史」右侧抽屉。

提交状态页有「查看任务进度」和「新建下一批」。前者打开该批历史详情；后者回到编辑表单并清空本批商品任务，允许再次创建至少 3 个新任务。已提交批次留在历史，不占据下一批的编辑区。

## 5. 历史与资产库

「生图历史」抽屉先列出批次，再进入批次详情；详情展示状态、完成比例、每个商品任务的原图、最终效果图、目标参数，以及可收起的商品卖点和设计风格。每个商品任务完成出图后，对应结果同步到资产库「素材 → AI生成」。

## 6. 验收标准

- 少于 3 个商品任务不能提交；任一任务无图时不能提交。
- 点击生成后必须先二次确认，确认前仍可返回修改。
- 确认后不出现逐任务提示词确认页，直接展示生成进度。
- 主图模式不展示详情图生成数量，详情图模式可设置数量。
- 「新建下一批」清空本批任务，但历史中仍可查看之前批次。
- 历史按批次与商品任务两级查看；最终效果图同步资产库。

## 7. 原型说明

原型通过前端计时模拟排队和生成，效果图使用演示素材；批次历史存于本机浏览器。真实并发控制、失败重试、计费、模型调用和服务端持久化尚未接入。
