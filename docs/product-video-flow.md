# 商品生视频：功能与交互说明

> 对应原型：[product-video.html](../product-video.html)。目标用户是需要从商品图快速制作电商短视频的运营与内容制作人员。

## 1. 产品目标

用户选择商品、配置视频内容及口播方式，先取得可编辑的视频策划和分镜，再提交生成。本次生成结果直接显示在右侧结果区；生成完成后不返回分镜。历史任务与生成素材分别进入历史抽屉和资产库「素材 → AI生成」。

## 2. 输入字段

| 字段 | 规则 |
| --- | --- |
| 商品 | 从商品库选择，或上传图片；至少 1 张图片，商品名称必填 |
| 商品名称、描述、卖点 | 可编辑；卖点可逐条新增、修改、移除 |
| 视频内容模式 | 预设视频类型或自定义视频内容，二选一 |
| 预设视频类型 | UGC 种草 / 测评、产品功能演示、生活场景展示、开箱介绍 |
| 语言、投放区域 | 独立选择；语言不再承担“无口播”含义 |
| 时长 | 10 秒、15 秒、30 秒 |
| 画面比例 | 9:16、1:1、16:9 |
| 人物参考图 | 选填，上传一张参考图 |
| 口播 | 默认“无口播”；可切换“有口播” |
| 口播音色 | 只在“有口播”时显示；选填；不选时采用默认音色；可在预设音色弹窗选择，也可清除选择 |
| 视频模型 | 在视频策划阶段选择，当前原型包含 Seedance 2 等演示选项 |

## 3. 主流程

1. 选择商品或上传商品图，填写名称、描述与卖点。
2. 选择预设类型或填写自定义内容，配置语言、区域、时长、比例、人物参考图和口播。
3. 点击「开始分析」。右侧生成摘要和按时长划分的分镜草稿。用户可编辑各镜头内容，也可输入调整要求更新策划。
4. 选择模型并点击「生成视频」。生成后右侧**直接显示本次结果预览**，上方只保留「新建视频任务」。结果页没有「查看分镜」或返回分镜入口。
5. 生成完成后保存本次全部字段、商品图、人物参考图、口播、音色、模型、分镜及结果预览到「历史」；资产库「AI生成」增加一个视频演示项。

## 4. 口播与分镜规则

- 选择「无口播」时，音色字段隐藏，分镜按画面、环境声与字幕组织，不要求口头台词。
- 选择「有口播」时，音色字段出现；用户可选择预设音色，也可以留空。摘要和分镜反映口播与音色设置。
- 切换回「无口播」时，当前策划按无口播规则重新分析后生效；音色选择不应出现在最终视频参数中。
- 用户在策划阶段可返回左侧修改配置；**生成完成后**不再提供返回分镜的操作。

## 5. 历史与下一次生成

顶部「历史记录」打开抽屉，按时间倒序列出任务。选中历史任务可查看原始输入、生成设置、分镜与本次结果预览；抽屉关闭后回到当前页面。历史详情中的「以此任务再次生成」复制旧任务配置到新的编辑任务，不覆盖旧记录。

结果区的「新建视频任务」清空本次商品和结果，回到配置状态。历史不长期铺在右侧，右侧只展示当前任务阶段。

## 6. 验收标准

- 没有商品名称或商品图时，「开始分析」不可用。
- 「有口播」时才出现音色入口；音色可不选，所选音色可清除。
- 修改分镜后，生成行为以修改后的分镜为准。
- 生成完成后，右侧展示本次结果，没有「查看分镜」按钮。
- 「新建视频任务」能开始下一次任务；上一条任务仍在历史中。
- 每次生成在资产库「AI生成」出现一个视频记录，并标明其为演示预览。

## 7. 原型与真实产品的区别

当前「生成视频」使用计时器模拟任务，右侧是静态封面，**没有真实可播放的视频文件**。预设音色可选择，但没有试听、克隆或真实语音合成。历史保存在本机浏览器；跨设备云同步、后端任务队列与真正的视频文件上传属于后续实现。
