# 模型管理：试生成提示词与边界

版本 v1.1，2026-11-12。流程见 [模型管理](model-management-flow.md)，正式接口见 [开发规格](custom-models-development.md)。

当前「试生成演示」仅接受可编辑文本，不上传用户素材，不调用模型、不生成或归档真实图片、视频或模型文案，不计费。以下为弹窗默认可复制文本，不是已上线后台服务。

## 图片默认文本

```text
展示一件白色棉质上衣，纯色背景，保留商品颜色和纹理。
```

## 视频默认文本

```text
展示一件白色棉质上衣，镜头缓慢推进，保持商品颜色与纹理，时长 15 秒。
```

## 输入、输出与验收

输入为去首尾空白1–2000字符文本，选择模型必须已启用且当前标签页存在测试Key。演示输出只是一段“图片/视频/文案试生成流程已完成”的UI文字，明确不是真实结果。记录只存时间、说明和demo=true，不保存提示词、Key或素材；不得归档成AI生成资产。用户可修改文本并重复演示。

正式试生成使用完整开发规格TrialRequest、按已声明operation校验、用户显式确认第三方额度后才提交。imageToImage必须有授权参考素材，imageToVideo需有效商品图，avatarSpeech需人物/商品与授权音频；不能用这些简单默认文本绕过输入要求。真实输出、时长与商品保真按适配器契约和业务验收判断，不能拿本地文字流程演示作为验证证据。

## 文案默认文本（v1.1）

```text
为一件白色棉质上衣写一段简洁的商品介绍，不编造未提供的功能或规格。
```

文案模型只输出本地流程完成说明，不输出真实 AI 文案。输入要求与其他两类相同，记录仅保存时间与演示状态。模型默认路由变化不改各业务后台提示词：商品分析、写作、提示词和脚本使用同一套已确认业务提示词，只把模型来源改为默认文案模型；AI 参考图使用默认图片模型。无新增素材处理或结果数量规则。
