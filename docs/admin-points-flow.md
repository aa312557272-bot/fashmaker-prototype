# Fash 积分后台 · 用户积分

[交互原型](../admin-points.html) · [字段契约](developer-field-contract.md#总后台用户积分)

## 操作流程

本页面属于 FashMaker 总后台，不属于创作工作台功能区。总后台入口、总览及未接入模块状态见[总后台流程](total-admin-flow.md)。

- 从 FashMaker 总后台的「Fash 积分」进入；总后台由工作台侧栏顶部 Logo 区域的「总后台」入口打开。用户积分页顶部提供总后台入口及「返回工作台」。进入「Fash 积分」，默认打开「用户积分」。顶部「调整积分」先选择用户，行内「调整」预选当前用户。按用户 ID、用户名或邮箱搜索，按余额筛选，点击数值列头切换升降序。筛选和排序回到第一页。
- 列表展示累计获得、累计消费、当前余额。点击「流水」查看时间、操作人、类型、使用功能、独立「调整说明」列、有符号变动和变动后余额，可按类型筛选。
- 选择增加或扣减，输入正整数，可填说明，确认后随该笔流水展示；未填写时显示「—」。核对弹窗显示目标用户及 ID、调整量与前后余额。确认前可返回修改或取消。余额不足时阻止提交，确认时若发现余额已变化，回到编辑步骤重新核对。
- 「注册积分配置」单独保存默认赠送积分，演示默认 100。

业务消费逐笔展示扣费时记录的功能，如商品生视频、商品详情长图、商品套图。缺少可识别功能的业务流水显示「未记录」，发放和人工调整显示「—」。旧版固定演示流水按示例定义补齐功能，已有调整记录和积分金额保留。

## 统计和演示边界

累计获得包含登记的入账与人工增加，累计消费只计算业务消费。人工扣减影响余额，并以独立流水类型展示。统计范围为全部历史。流水按时间倒序显示，逐笔余额按完整流水计算后再筛选。

演示使用虚构用户和独立浏览器存储 `fashmaker-admin-points-v1`，与账户中心示例数据独立。截图中原有行内余额保存改为有确认步骤的按量调整，注册配置移入独立页签。正式接入时由服务端以用户 ID 授权与记账，原子写入积分余额及流水并对请求去重，浏览器演示数据仅供验收。

## 验收

- 搜索 1601 能定位示例用户，搜索不存在的用户显示空态，清空恢复列表。筛选零余额后仅显示零余额用户。
- 对 1601 增加 100，累计获得与余额都增加 100，业务消费保持原值，流水新增一条人工增加记录。
- 对该用户扣减 30，余额减少 30，累计获得与业务消费保持原值。扣减超过余额时无新增流水。
- 取消确认无数据写入。刷新后，已确认的调整和注册积分配置可从本机读取。

- 填写调整说明并确认后，打开该用户「流水」，对应记录的「调整说明」列显示原文，刷新后仍可查看。
- 示例用户 1601 的 860 积分消费显示为「商品生视频」。按「业务消费」筛选后，功能和变动后余额仍可见。
