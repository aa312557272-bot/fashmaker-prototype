# 图文笔记 Agent · 流程与开发说明

原型：[graphic-notes.html](../graphic-notes.html)。字段以[开发字段契约](developer-field-contract.md#10-图文笔记-agent)为准；后台交付见[完整提示词](graphic-notes-prompt.md)。

## 入口与创作

左侧导航「图文笔记」直接进入 Agent 工作台，无任务列表中间页。延续当前深色界面，左侧为素材、对话与输入框，右侧为生成内容。顶部仅新建与历史。商品详情的「用此商品创作」也支持进入。

素材选填，本地选择每次替换全部输入，最多 9 张，每张 10 MB，JPG/PNG/WEBP；读取成功后压缩为最长边 1200px JPEG，历史仅保留结果图，不保存输入素材或原始字节。失败保留原输入。商品库单选带入最多 9 张图及稳定 productId。上传、清空素材解除商品关联。仅文字也可发送。输入 1–2000 字符，Enter 发送，Shift+Enter 换行，兼容中文输入法。

发送后右侧显示生成进度，锁定输入、新建和历史；模拟完成生成标题、正文、话题与配图。继续对话产生新版本，保留以前版本，不覆盖旧结果。当前模板不会理解自然语言指令、识别图片或真正生成图片；有素材时按原顺序排版素材，无素材时使用 4 张本地 SVG 服装风格示意。

## 预览、下载与发布

默认全文模式：左图右文，配图有前后翻页及数量。平铺模式：所有配图网格与完整正文。封面预览：首图、标题与平台封面说明。同一版本三种模式共享内容，切换不重新生成。顶部版本选择可回看历次结果。

生成后启用发布，弹窗多选平台，默认小红书，至少选择一项。确认仅记录本机模拟提交，不登录、不填充创作者网页、不发送真实内容。记录绑定所选 versionId 和版本序号，重复提交分别记录。生成前禁用发布与下载。

下载为完整 JSON，包含当前版本标题、正文、话题和全部图片数据，非图片压缩包。

## 历史、归档与失败

IndexedDB `fashmaker-graphic-notes` / `tasks` 仅保存生成结果：各版本标题、正文、话题、配图、资产 ID，以及任务与商品关联标识、时间和发布状态。不保存对话、用户生成要求或输入素材快照。对话仅在当前页面内存中保留。每次生成或模拟发布后保存结果；刷新后从历史打开。

历史为右侧抽屉，仅展示各版本图文结果及发布状态；「查看此结果」恢复右侧预览，左侧不恢复对话或输入素材。移除复制历史输入的再次生成入口；可查看结果后重新输入要求。新建清空素材、对话、版本、商品关联及发布，恢复全文模式。数据库升级至 v2 时自动清理旧历史中的对话、生成要求和输入快照，保留已有结果。

每个版本的每张配图各建一个共享资产（source=图文笔记、type=image、demo=true），带 taskId 和明确选择时的 productId；进入 AI生成及对应商品详情。上传不推断商品关联。先保存共享资产，再保存历史，历史失败回退资产，保留本次输入供重试。不提供服务器事务或跨标签并发保证。

## 验收与差异记录

1. 所有现有页面导航能直接进入，不出现任务管理列表。
2. 文字或素材对话产生演示结果，生成中阻止重复提交与修改输入。
3. 全文翻图、平铺全部配图、首图封面，版本切换不串图文。
4. 发布至少选一项，成功提示明确是模拟；JSON 下载包含所有配图。
5. 刷新可回看全部版本结果，历史不含对话、生成要求或输入快照；新建完全清空。
6. 商品来源按稳定 ID 关联资产，纯上传不关联；存储失败不显示成功。
7. 桌面左右布局、窄屏上下布局，无整体横向溢出。

## 自定义模型与导航修订（2026-11-10）

移除顶部横向功能快捷导航，保留左侧功能导航。通过左侧「自定义模型」管理配置；窄屏顶部提供同名入口。图片功能只列出图片模型，视频功能只列出视频模型；平台原有选项保留，保存后即加入对应下拉，切换本次模型不要求逐步选择。文字分析、文案、提示词和脚本使用默认文案模型，可在模型管理选择平台或某个自配文案模型。详细字段、演示边界及验收见 [自定义模型配置](custom-models-flow.md)。


### 2026-11-10 布局统一修订

所有页面侧边栏采用 shared-sidebar.js / shared-sidebar.css 的同一结构与样式：216px 宽、FashMaker 品牌与副标题、首页、创作工具、管理、账号区；菜单顺序为视频创作、详情长图、商品套图、商品生视频、爆款复刻、AI 换装、穿搭分离、数字人口播、图文笔记、资产库。仅当前功能高亮变化。批量页也使用同一侧栏。模型管理保留在管理区域；设置按钮打开模型配置，创作记录打开当前功能历史。首页和视频创作暂分别链接现有详情页和商品视频页，不新增独立功能。

模型选择统一放在创作设置末尾、生成提示及按钮前；AI 换装清晰度在模型之前。商品生视频与爆款复刻模型从右侧策划区迁到左侧设置末尾。批量全局和单任务覆盖的模型均为最后参数；图文笔记放在输入框之后、发送操作之前。移动 DOM 保留原 select ID、事件与选择值，模型默认与路由以[模型管理 v1.1](model-management-flow.md)为准，生成内容规则不变。窄屏仍隐藏主侧栏，保留顶部模型管理入口。
