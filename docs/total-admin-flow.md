# FashMaker 总后台入口与配置总览

## 入口和归属

创作工作台侧栏顶部的 FashMaker 品牌区域新增「总后台 ↗」入口，进入 `total-admin.html`。后台积分不再出现在工作台的「管理」导航；`admin-points.html` 属于 FashMaker 总后台，页头品牌链接回总后台，另提供「返回工作台」离开总后台。

总后台采用独立于工作台的浅色管理框架，左侧包含「总览」「Fash 积分」「注册积分配置」。总览页展示平台管理说明、可用配置模块入口及未接入模块状态。Fash 积分和注册积分配置链接到 `admin-points.html` 对应区块（`#settings` 直接定位配置页签）。计费配置和计费费率目前仅作为未接入入口说明展示，不声称已经实现。

## 页面行为

- 顶部「返回工作台」回到 `index.html`。
- 总览的 Fash 积分卡进入用户积分列表；注册积分配置卡以 `#settings` 打开注册积分配置区。
- 用户积分页的左侧总后台导航可在总览、Fash 积分和注册积分配置之间跳转。
- 所有数据继续使用本机 localStorage。Fash 积分数据键 `fashmaker-admin-points-v1` 与账户中心账本独立；原有用户、流水、调整及注册积分配置不迁移、不改数值。
- 当前总后台为静态演示入口，不具备真实平台管理员身份鉴权；未接入的配置项只展示状态，不允许误认为可用配置。

## 验收口径

1. 工作台侧栏顶部可见「总后台」入口并进入总后台总览；管理导航不再单列用户积分。
2. 总后台总览可进入 Fash 积分与注册积分配置，配置链接直接打开正确页签。
3. Fash 积分页品牌入口回总后台，返回工作台仍能离开后台。
4. 既有积分调整、流水和注册默认积分数据保持原样、刷新后仍在本机读取。
5. 计费配置和计费费率清晰标记未接入，不会展示虚构的可编辑配置。
