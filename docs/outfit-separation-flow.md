# FashMaker 穿搭分离 · 功能与开发说明

对应原型：[outfit-separation.html](../outfit-separation.html)。2026-11-09 新增，方案已由用户确认。精确口径见 [开发字段契约第 8 节](developer-field-contract.md#8-穿搭分离)。

## 1. 入口和布局

独立「穿搭分离」入口，所有创作页顶部导航可达，侧栏提供入口。商品详情「用此商品创作 → 穿搭分离」带入首张参考图与稳定商品 ID。复用 FashMaker 深色框架、浅绿主按钮、左配置右结果、顶部新建与历史。窄屏上下布局。

## 2. 输入与生成

- 单张模特穿搭图必填；本地上传、拖拽、素材库单选或商品库单选。再次选择替换，仅拖入多张时取首张。
- JPG/JPEG/PNG/WEBP，单张不超过 10 MB；同时校验后缀、MIME 与可读性。压缩至最长边 1200px JPEG 保存到历史，不能按无损原图验收。
- 可预览和移除。失败保留原可用输入；读取过程中禁用提交，防止旧图片参与生成。
- 无其他必填参数。输出一张完整白底穿搭平铺合集图，所有服装、鞋包和配饰整理在同一画布中，不重叠、不含人物或文字。正式服务按可见的上装、外套、下装、连体装、鞋履、包袋与配饰逐件分离，不补充原图未出现的单品。
- 一键直接提交，不需提示词确认；处理中禁用输入、新建与重复提交；完成后输入只读。失败保留输入可重试。

## 3. 演示边界和结果

默认三套本地平铺示例，可点击「使用此示例」。每套将单品合并到一张竖版平铺图中。都市通勤使用用户提供的平铺参考图，其余两套使用本地矢量平铺示意。普通上传或商品库输入统一使用都市通勤示例，明确标注结果与上传图片实际服装无关，未进行识别或抠图，不能把示例中的单品宣称为识别结果。

结果区只显示一张完整穿搭平铺图，支持预览与 PNG 下载，不拆成单品卡片或 ZIP。当前不调用模型、不计费。按用户要求删除左侧「一张穿搭，逐件拆解」说明面板及「当前为交互演示」提示区块；结果区保留简短示例标识。用户提供的平铺图作为内置参考示例，不表示已接入真实识别。

## 4. 历史与新建

独立本机 IndexedDB `fashmaker-outfit-separation` / `tasks` 保存 taskId、输入压缩图、来源、assetId、商品关联、exampleId、生成要求、结果 PNG data URL、各结果资产 ID、创建时间。历史以右侧模态抽屉倒序展示，可查看原输入、全部结果及要求、下载示例。

「以此任务再次生成」复制完整输入与生成要求，分配新 taskId，清空结果及创建时间，关闭抽屉并恢复编辑；需点击分离按钮提交，不修改旧历史。「新建」清空输入、商品关联、示例选择、结果并恢复默认要求。刷新只保留已完成历史，不恢复未提交草稿。

## 5. 归档和商品关联

每次仅将一张完整平铺图写入现有共享 `fashmaker-prototype-generated-assets`，source=穿搭分离、type=image、demo=true，保留独立 id、taskId、productId、productName、preview、createdAt。结果同时显示在 AI生成和所关联商品详情。仅素材选择不推断商品 ID；替换本地、素材、示例或移除解除旧商品关联。历史输入引用不因删除 AI生成结果而消失。

原型先写共享结果再写历史，历史失败时恢复写入前资产；失败不显示完成，并保留输入供重试。该跨存储回退不具备服务端事务或多标签并发保证，正式接入需事务化归档，防止重复或覆盖。存储读取异常明确提示。

## 6. 验收

1. 默认不能提交；有效单图可以提交；错误类型、超 10 MB、损坏文件不能替换已有输入。
2. 示例选择、普通上传、素材选择都清除旧商品关联；商品库与商品详情入口保留稳定 ID。
3. 处理中与完成后不能改变输入；新建恢复为空；历史复制产生不同任务 ID。
4. 一张 PNG 平铺结果归档，历史刷新可回看，商品关联按 ID 展示。
5. 下载完整 PNG 平铺图，结果标为示例；图二对应的两个左侧说明区块已移除。
6. 本机存储失败显示错误并允许重试，无虚假完成提示；桌面与窄屏无横向溢出。

## 7. 与现有口径的差异

本次新增独立功能，不改变换装四页签。本页支持实际下载本地 PNG 平铺示例，与其他原型仅提供下载演示提示不同；不表示已接入真实模型结果下载。README 与字段契约已补充此边界。

2026-11-09 用户修订：输出由每件独立图片改为一张白底穿搭合集平铺图；历史旧任务保留原结果，再次生成按新的单图规则处理；不迁移或删除旧资产。

移除顶部横向功能快捷导航，保留左侧功能导航。通过左侧「自定义模型」管理配置；窄屏顶部提供同名入口。图片功能只列出图片模型，视频功能只列出视频模型；平台原有选项保留，保存后即加入对应下拉，切换本次模型不要求逐步选择。文字分析、文案、提示词和脚本使用默认文案模型，可在模型管理选择平台或某个自配文案模型。详细字段、演示边界及验收见 [自定义模型配置](custom-models-flow.md)。


### 2026-11-10 布局统一修订

所有页面侧边栏采用 shared-sidebar.js / shared-sidebar.css 的同一结构与样式：216px 宽、FashMaker 品牌与副标题、首页、创作工具、管理、账号区；菜单顺序为视频创作、详情长图、商品套图、商品生视频、爆款复刻、AI 换装、穿搭分离、数字人口播、图文笔记、资产库。仅当前功能高亮变化。批量页也使用同一侧栏。模型管理保留在管理区域；设置按钮打开模型配置，创作记录打开当前功能历史。首页和视频创作暂分别链接现有详情页和商品视频页，不新增独立功能。

模型选择统一放在创作设置末尾、生成提示及按钮前；AI 换装清晰度在模型之前。商品生视频与爆款复刻模型从右侧策划区迁到左侧设置末尾。批量全局和单任务覆盖的模型均为最后参数；图文笔记放在输入框之后、发送操作之前。移动 DOM 保留原 select ID、事件与选择值，模型默认与路由以[模型管理 v1.1](model-management-flow.md)为准，生成内容规则不变。窄屏仍隐藏主侧栏，保留顶部模型管理入口。
