# FashMaker 个人菜单与账户中心交互

版本：v1.0｜更新：2026-11-13｜状态：已确认交互，本地演示已实现。

本文独立定义个人菜单、积分与订单明细、多团队、成员邀请、派送积分。价格、套餐和积分包统一见[价格体系](pricing-system.md)，不在本文件重复维护价格。

当前HTML使用本机浏览器存储，不连接真实账号、邮件、支付或积分服务。

## 1. 个人菜单

全站底部账号区及已有顶部头像可打开同一个菜单；窄屏侧栏隐藏时，右上角保留头像按钮。当前示例账号Ricky Tang，头像R；不复制参考图中的私人账号信息。

| 顺序 | 菜单项 | 显示与点击行为 |
| --- | --- | --- |
| 1 | 账号 | 展示头像及账号名称 |
| 2 | 积分 · 充值 | 显示当前空间实时本地余额，点击打开三Tab购买弹窗 |
| 3 | 邀请有礼 | 进入当前空间积分明细，预筛选「邀请奖励」 |
| 4 | 联系我们 | 显示未接入提示，不发送真实客服消息 |
| 5 | 积分明细 | 进入账户中心积分页 |
| 6 | 订单明细 | 原充值记录更名，进入账户中心订单页 |
| 7 | 当前团队 / 个人账户 | 保留当前名称，右侧显示「切换」；整行直接进入当前空间成员页 |
| 8 | 账号管理 | 暂未接入提示 |
| 9 | 退出系统 | 暂未接入提示，不伪造真实退出登录 |

「当前团队」不再展开菜单中的二级团队列表。进入账户中心后，统一通过顶部空间选择框切换个人账户及各团队，并可创建团队。个人空间点击同样进入成员页空态，不改变当前空间或自动创建团队。

菜单支持Esc、关闭按钮及外部点击关闭；取消关闭不改数据。账号区空间名称、菜单余额和已有顶部积分按钮同步当前空间。

## 2. 账户中心页面

独立页面account-center.html，保留全站主侧栏，内容左侧仅三个页签：积分明细、订单明细、成员管理。移动端将这三个页签转为横排。

路由：account-center.html?tab=credits|orders|members&workspace=<稳定空间ID>。无tab默认credits；无workspace沿用本机当前空间。切换、刷新及浏览器前进/后退保持目标空间和页签。不存在空间提示错误，不展示其他空间账目。

| 页面 | 充值 / 升级 | 派送积分 | 派送记录 | 页面业务操作 |
| --- | --- | --- | --- | --- |
| 积分明细 | 显示 | 显示 | 显示 | 搜索、类型/成员/日期筛选、流水详情 |
| 订单明细 | 不显示 | 不显示 | 不显示 | 搜索、类型/状态筛选、订单详情 |
| 成员管理 | 不显示 | 不显示 | 不显示 | 邀请、编辑、取消邀请、模拟接受、移除 |

创建团队和空间切换为账户中心公共入口；个人成员页不提供邀请按钮，显示无需成员管理提示并保留创建/切换入口。

## 3. 积分明细

积分明细同时记录支出和收入，不能把收入统称消费扣款。

| 字段 | 规则 |
| --- | --- |
| 流水号 | 每条流水稳定唯一，可点击查看详情 |
| 标题 | 业务说明，退款显示关联原消费单号 |
| 成员 | 发生时成员名称及账号快照，关联稳定memberId |
| 变动类型 | 消费、退款、充值、赠送、邀请奖励、派送支出、派送收入 |
| 变动积分 | 有符号整数，消费/派出为负，收入为正，颜色辅助区分 |
| 剩余积分 | 当前空间按时间升序逐笔累计到该条的余额，列表按时间倒序 |
| 变动时间 | 时间戳，按Asia/Shanghai展示 |

详情补充空间、关联订单/流水、派送单号、来源账户、接收团队、对方流水及备注。个人和每个团队只查看自己的记录，不合并不同团队。

邀请好友获得的积分作为正向「邀请奖励」进入同一明细。邀请团队成员与邀请好友活动不同，创建成员邀请或模拟接受不自动发积分。示例奖励金额不构成正式活动规则。

退款保留原消费，另加正向退款流水关联原单，不删除原消费或重复抵扣。余额=sum(delta)；累计获得=sum(正数且非退款)，包括派送收入；累计净消费=max(0,-sum(消费与退款))。成员累计用量按当前团队和memberId计算相同净消费，不计派送。

筛选支持流水号/标题、类型、成员、起止日期，取交集；日期按上海时区包含全天。额外提供「派送记录（收入/支出）」组合筛选。筛选不改变账户余额或历史单笔余额。

分页默认20，可选5/10/20/50；条件改变回第一页。无结果明确提示，无需清空历史。

## 4. 订单明细

顶部显示当前空间套餐与剩余积分，无充值/升级按钮。

字段：订单号、商品/套餐、订单类型、购买周期、支付金额、订单状态、下单时间、支付时间、操作人、详情。订单类型为会员/积分包；状态为待支付/已支付/已关闭/已退款。金额以整数分存储、元两位小数展示。未支付时间显示暂无。

支持订单号/商品搜索、类型及状态筛选、分页与只读详情。没有订单显示空态。现有充值咨询或选择积分包不创建已支付订单、不自动到账，不提供真实付款或退款操作。

## 5. 多团队与成员管理

### 5.1 创建与切换团队

可创建多个团队。名称trim后必填1–50字符，本机团队不可同名，使用稳定UUID衍生ID关联数据。创建后切换到该团队成员页，创建者为所有者。

新建和示例团队均明确为「团队版 · 演示」，不产生购买或增加真实订阅；不改变个人版、自定义模型版不含团队功能的已确认价格规则。新团队积分0，无订单，仅有创建者。

个人与每个团队的账目、订单、成员分别保存；切换不删除原空间数据。本次隔离仅覆盖新增账户中心，不表示现有商品、资产、模型配置或创作任务已接入真实团队租户权限。

### 5.2 成员字段

| 列 | 定义 |
| --- | --- |
| 成员 | 用户名及邮箱 |
| 备注 | 职责或其他备注 |
| 角色 | 所有者、管理员、成员 |
| 状态 | 待加入、已加入、已取消、已移除 |
| 加入时间 | 未加入展示暂无 |
| 累计用量 | 当前团队成员消费减退款的净用量 |
| 额度上限 | 不限或非负整数，0有效 |
| 最后登录 | 未有记录展示暂无，不伪造真实登录 |
| 操作 | 按状态展示编辑、邀请链接、模拟接受、取消邀请或移除 |

### 5.3 邀请与编辑

邀请表单：邮箱必填且有效，trim转小写、最多254字符；备注选填最多100；角色默认成员，可选管理员；额度上限留空表示不限，否则必须为非负安全整数。同团队在册成员或待加入邀请不能重复邮箱，不同团队可分别邀请同一邮箱。

创建邀请仅写入本地「待加入」，不发送邮件。可以查看并复制演示邀请链接、取消或显式模拟接受；接受后状态改已加入并记加入时间，不伪造登录时间。链接只在含该本地数据的同一浏览器可用；取消或接受后清理token，旧链接不能重复接受。

编辑可修改备注、角色、额度，不改邮箱。移除保留成员ID与原流水归属，历史不删除。所有者不可移除或降级；当前账号必须为active owner/admin才能管理。额度字段仅演示保存，不实施真实生成限额。

邀请表单锁定打开时的空间；跨页切换后提交旧表单提示重新发起，避免邀请到错误团队。保存失败保留输入并说明原因。个人空间不提供成员邀请。

## 6. 个人向团队派送积分

只从积分明细页发起；成员管理不显示派送入口。

弹窗显示来源账号及个人余额、接收团队、当前团队余额、派送积分和备注。团队积分页默认当前团队，个人积分页默认第一个本人可管理团队。来源固定个人账户，目标仅限本人为active owner/admin的团队。

| 输入 | 校验 |
| --- | --- |
| 接收团队 | 必须为有效、本人可管理的团队 |
| 派送积分 | 必填正安全整数，不大于提交时最新个人余额 |
| 备注 | 选填，trim后≤200字符 |
| 当前空间 | 提交时须与打开表单时一致，否则重新发起 |

确认后在同一个本地状态写入一对流水：个人transfer_out=-amount，团队transfer_in=+amount。同一个transferId，独立流水ID，记录来源/目标ID及名称、操作人、时间、备注，linkedLedgerId相互关联。

个人余额减、目标团队增，总积分守恒，其他团队不变。不创建支付订单、不增加赠送、不计成员消费，不支持团队向个人退回或团队互转。同一派送请求重复提交不再次扣减，内容不一致则拒绝；写入失败两边都不落账。

「派送记录」展示当前空间的派送单号、来源账号、接收团队、带符号变动积分、操作成员、时间、备注。个人显示派出，目标团队显示收到；另一团队不显示这笔。暂无派送显示空态，不伪造历史。

## 7. 存储与演示边界

共享account-store.js，localStorage键fashmaker-account-center-v1，包含version/currentWorkspaceId/workspaces/ledger/orders。成功保存后发布事件同步页面和菜单，跨标签通过storage刷新。

首次提供个人账户及两个团队示例：个人余额420，团队各3820；新团队0。这些仅为示例流水，不是会员赠送或邀请奖励定价。旧本地数据兼容新增派送类型，无需清空数据。

没有真实账号、付款、邮件、奖励、积分批次过期、额度执行或创作自动扣费。正式实现需服务端租户鉴权、订单回调幂等、积分账本事务及批次校验；不能把浏览器一次完整写入视为分布式事务。

## 8. 验收清单

1. 头像菜单有积分明细与订单明细；团队右侧显示切换，整行直达当前成员页，无二级团队菜单。
2. 账户中心只有三个页签；成员页无充值/升级和派送按钮，订单页无充值/升级。
3. 多团队稳定ID隔离，创建后空账目且创建者为所有者；切换和刷新保留目标空间。
4. 成员邀请待加入、取消、模拟接受、编辑与移除可用；所有者受保护，邀请不发邮件或自动送积分。
5. 积分包含成员字段和邀请奖励，退款不重复抵扣，筛选不改余额；订单详情及空态正确。
6. 个人派送100后两侧-100/+100同单号，其他团队不变；重复、余额不足、非法金额和存储失败不产生错误流水。
7. 桌面与390px页面不横向溢出，表格内部滚动；键盘、Esc、外部关闭、表单错误与焦点恢复可操作。
