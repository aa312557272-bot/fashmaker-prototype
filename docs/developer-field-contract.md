# 开发字段字典与结果归档规则

本页列出当前原型实际提供的选项。下拉值应作为枚举维护；显示文案与提交值可以分开，但历史快照必须保存提交值及生成时显示文案。默认值按当前原型，正式默认值如需调整须由产品确认。

## 1. 通用商品与结果关联

| 字段 | 类型 / 规则 |
| --- | --- |
| `productId` | 商品库商品的稳定 ID。从商品详情进入创作、或从商品库选择商品时必填；纯上传图片时为空。商品改名不能改变 ID。 |
| `productName` | 生成时的商品标题快照，便于历史显示；不能替代 `productId` 关联。 |
| `taskId` / `batchId` | 来源任务及批次 ID；重复生成产生新任务 ID。 |
| `assetId` | 每张生成图或视频各有唯一 ID；同一个资产记录可同时在 AI 生成列表和所属商品详情中展示，不复制二进制文件。 |
| `assetType` | `image` / `video`；详情长图为一张 `image`，套图逐张建 `image`，批量按各商品任务逐张建资产。 |
| `source` | 商品详情长图 / 商品套图 / 商品生视频 / 批量商品主图 / 批量详情图。 |

生成成功时先落库资产，再建立 `productId → assetId` 关联；更新历史任务结果引用。商品有 ID 时，结果同时显示在「资产库 → 素材 → AI 生成」和「资产库 → 商品 → 对应商品详情 → 素材」；无商品 ID 时只进入 AI 生成，不靠同名或相似图片猜测归属。失败或取消不建结果资产。商品详情删除关联素材，只解除关联；从 AI 生成删除资产时，同步移除商品详情中的同一结果引用。商品被删除时，生成资产及历史仍应保留，原商品引用转为空。页面刷新和跨入口跳转后关联仍应存在。

当前静态原型用浏览器本地存储模拟结果和商品关联，并使用演示预览图；正式版由服务端保证资产创建、关联与历史写入一致性。

## 4. 商品生视频

| 字段 | 选项 / 限制 | 默认 |
| --- | --- | --- |
| 商品 | 从商品库选择或上传图片；商品名称必填，图片至少 1 张，最多 6 张 | 空 |
| 描述、卖点 | 描述自由文本；卖点可逐条增删改 | 空 |
| 内容模式 | 预设视频类型 / 自定义视频内容 | 预设 |
| 预设类型 | UGC 种草 / 测评、产品功能演示、生活场景展示、开箱介绍 | UGC 种草 / 测评 |

| 投放区域 | 美国、中国大陆、日本、英国、东南亚 | 美国 |
| 时长 | 10 秒、15 秒、30 秒 | 15 秒 |
| 画面比例 | 9:16、1:1、16:9 | 9:16 |
| 人物参考图 | 可选，1 张图片 | 空 |
| 口播 | 无口播 / 有口播 | 无口播 |

## 5. 批量生图

| 字段 | 选项 / 限制 | 默认 |
| --- | --- | --- |
| 批量类型 | 商品主图 / 详情图；仅从对应单品创作页进入 | 来源页 |
| 商品任务 | 至少 3 个；每任务 1–6 张图片，顺序为商品图 → 商品卖点与 AI 帮写 → 设计风格 → 参数覆盖 | 入口带入一个任务或空 |
| 目标平台 | 智能匹配、淘宝、天猫、京东、拼多多、抖音电商、1688、TikTok Shop、Amazon、Shopee、Lazada、Temu、AliExpress、Shopify | 智能匹配 |
| 目标市场 | 美国、加拿大、英国、德国、法国、西班牙、意大利、中国大陆、日本、韩国、新加坡、马来西亚、泰国、越南、印度尼西亚、菲律宾、阿联酋、沙特阿拉伯 | 美国 |
| 目标语言 | 无文字(纯视觉)、简体中文、繁体中文、英语、西班牙语、日语、韩语、德语、法语 | 无文字(纯视觉) |
| 模型 | Nano Banana 2、GPT Image 2.5、Flux Kontext | Nano Banana 2 |
| 画面比例 | 1:1 正方形、Auto 智能匹配、4:3 横图、3:2 横图、16:9 横屏、3:4 竖图、4:5 竖图、9:16 竖屏、1:3 超长图 | 1:1 正方形 |
| 清晰度 | 1K 标准、2K 高清、4K 超清 | 1K 标准 |
| 详情图生成数量 | 1、2、3、4、6 张；仅详情图批量模式显示 | 1 张 |
| 主图模块 | 智能模块 / 自定义模块；自定义按套图类型与张数配置 | 智能模块 |
| 单任务覆盖 | 可覆盖以上全局参数；未覆盖项继承全局。覆盖下拉必须使用与全局相同枚举 | 继承全局 |

批量任务不先生成提示词：校验至少 3 个任务和各任务至少一张商品图 → 二次确认 → 直接生图。每个商品任务完成时，独立建立结果资产和商品关联；批次部分成功时只归档成功项。历史按批次与商品任务展示结果和完整参数快照。
