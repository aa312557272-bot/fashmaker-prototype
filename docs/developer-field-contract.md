# 开发字段字典与结果归档规则

本页列出当前原型实际提供的选项。下拉值应作为枚举维护；显示文案与提交值可以分开，但历史快照必须保存提交值及生成时显示文案。默认值按当前原型，正式默认值如需调整须由产品确认。

## 1. 通用商品与结果关联

| 字段 | 类型 / 规则 |
| --- | --- |
| `productId` | 商品库商品的稳定 ID。从商品详情进入创作、或从商品库选择商品时必填；纯上传图片时为空。商品改名不能改变 ID。 |
| `productName` | 生成时的商品标题快照，便于历史显示；不能替代 `productId` 关联。 |
| `taskId` / `batchId` | 来源任务及批次 ID；重复生成产生新任务 ID。 |
| `assetId` | 每张生成图或视频各有唯一 ID；同一个资产记录可同时在 AI 生成列表和所属商品详情中展示，不复制二进制文件。 |
| `assetType` | `image` / `video`；详情长图为一张 `image`，套图逐张建 `image`，批量按各商品任务逐张建资产。 |
| `source` | 商品详情长图 / 商品套图 / 商品生视频 / 爆款复刻 / 批量商品主图 / 批量详情图。 |

生成成功时先落库资产，再建立 `productId → assetId` 关联；更新历史任务结果引用。商品有 ID 时，结果同时显示在「资产库 → 素材 → AI 生成」和「资产库 → 商品 → 对应商品详情 → 素材」；无商品 ID 时只进入 AI 生成，不靠同名或相似图片猜测归属。失败或取消不建结果资产。商品详情删除关联素材，只解除关联；从 AI 生成删除资产时，同步移除商品详情中的同一结果引用。商品被删除时，生成资产及历史仍应保留，原商品引用转为空。页面刷新和跨入口跳转后关联仍应存在。

当前静态原型用浏览器本地存储模拟结果和商品关联，并使用演示预览图；正式版由服务端保证资产创建、关联与历史写入一致性。

### 6.1 正式链接导入契约（待接入）

完整接入方案见 [结构复刻开发说明 3.2.1](viral-remix-flow.md#321-链接拉取的开发方案待接入)。以下为正式服务建议字段，不是当前原型已经提供的线上接口。

| 字段 / 规则 | 交付口径 |
| --- | --- |
| importId | 一次异步链接导入任务的唯一 ID，与创作 taskId 分开 |
| inputVersion / idempotencyKey | 防止旧响应覆盖当前输入，并避免重复创建来源资产 |
| status | 建议 queued、resolving、downloading、validating、storing、succeeded、failed、canceled |
| source.assetId | 真实文件下载、校验与入库成功后才提供；只有平台临时播放地址不视为成功 |
| 视频元信息 | platform、platformVideoId、canonicalUrl、title、mimeType、sizeBytes、durationMs、width、height、previewUrl、posterUrl |
| 来源归档 | 链接导入的原视频进入上传素材，不进入 AI生成；后续生成结果仍按原有 productId / taskId 规则归档 |
| 失败兜底 | 分类错误、retryable 与有限重试；允许本地上传或资产库替代；失败不产生可分析的成功来源资产 |

当前 HTML 的链接拉取依旧为模拟，不改变现有字段默认值和本地上传限制。
