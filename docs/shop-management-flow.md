# 店铺管理与小红书商品导入：当前 Demo

更新：2026-11-11。原型：[店铺管理](../shop-management.html)、[资产库](../asset-library.html?tab=products)。正式后端接入目标另见[小红书开发规格](xiaohongshu-publishing-development.md)；本页描述已经实现的静态交互。

## 1. 入口与页面

统一侧栏在「管理」区域新增「店铺管理」，所有创作页及资产库共用 shared-sidebar.js。窄屏提供顶部同名链接。新页沿用深色与绿色主操作样式，包含小红书平台标识、连接店铺数、导入商品数、冲突数，以及「已连接店铺 / 同步记录 / 发布记录」。本期只展示小红书，不放置不可用的其他平台按钮。

首次无店铺，显示连接引导。模拟授权弹窗可选择「FashMaker 生活选物店」或「FashMaker 服饰精选店」，勾选演示说明后确认。同一示例店铺重复连接不新增；断开后保留商品、历史和生成结果，重新连接恢复操作。店铺卡片显示连接状态、示例sellerId、导入数量与最近同步时间。

## 2. 模拟商品同步

点击「同步商品」或商品库「从店铺导入」，弹窗提供已连接店铺选择、标题搜索、逐商品勾选、全选当前结果和选择全店。每家店铺初始有6个示例商品，包含5个在售与1个下架商品；示例价格和库存明确为演示数据。

确认前已选数量为0时按钮禁用。提交中禁止重复操作与关闭；保存后展示逐项新增、刷新、无变化或冲突结果，提供前往来源店铺商品库的链接。导入任务按店铺保存时间和逐项结果。

去重按shopId+itemId，内部商品ID固定为xhs-shopId-itemId；不同店的同名商品不合并。既有商品和新导入商品共用商品库，不建立第二份可编辑商品列表。商品页可按来源店铺及同步状态筛选，来源信息显示于网格和列表。

本机演示只保存示例图片链接，不执行真实素材下载；网络图片失败时展示本地SVG示例占位。来源图片在「上传素材」显示，标注「小红书来源 · 演示预览」，不进入AI生成。没有实现全店接口分页、SKU分页、原文件校验和服务端断点任务；这些属于正式接入目标。

## 3. 商品详情、差异与创作

导入商品详情顶部显示来源店铺、itemId、最近模拟同步、价格库存快照与连接状态，提供刷新、查看差异、模拟店铺修改、更新回原商品。未保存标题/描述时，刷新和差异操作提示先保存，避免丢弃输入。普通商品提供「发布到小红书」。

「模拟店铺修改」会改变本机来源版本的标题及描述，并执行一次模拟同步。比较上次来源基线、本地字段和新来源：本地未改可安全刷新；本地修改而来源未变则保留；双方变化且值不同则保存冲突，默认选保留本地，也可采用店铺值。当前差异演示仅覆盖标题和描述，不宣称已对全部SKU、图片或动态属性做三方合并。

有未解决冲突时禁止模拟回写；来源店铺断开时禁止刷新或回写。商品名称改变不更换稳定productId；商品打开和批量商品选择使用稳定ID，避免多店同名商品误操作。商品库过滤后「全选当前列表」仅选择当前可见商品。

原有商品详情的详情图、套图、视频等创作入口保留，继续使用productId传递与关联。新生成结果按原规则出现在AI生成和该商品详情；来源素材与生成结果分开。

## 4. 发布与更新演示

从导入商品进入，目标锁定来源店铺与itemId；从普通商品进入，可选择已连接示例店铺，作为新品模拟提交。发布弹窗从商品详情当前标题、描述及关联图片带入，不自动保存或覆盖商品库文本。

第一步补全示例类目、品牌说明、单规格、价格库存与示例物流，选择图片用途（不使用/主图/详情图/兼用）。默认首图兼作主图和详情图，其余不使用；生成图片也可作为候选；视频或视频演示封面不会被当图片/成片上传。当前仅示例单规格、图片发布，不含真实商品视频、动态类目属性、多SKU完整编辑。

第二步显示店铺当前示例内容和本次提交内容，用户勾选确认后才可模拟提交。发布中锁定操作，防止重复；结果默认「模拟待审核」，提供「模拟审核通过并上架」「模拟审核不通过」两种结果。失败原因是固定示例，并非平台反馈。

模拟通过会更新本机来源版本；普通商品首次模拟通过后建立店铺商品映射，后续可更新回该示例商品。结果不会新增一份AI资产。发布记录保存提交快照及状态，可查看来源商品；提交后编辑商品不会改变历史快照。

## 5. 存储与演示边界

- `fashmaker-shop-demo-v1`：shops、tasks、publications、sources，分别保存示例连接、同步任务、发布快照与店铺侧改动。纯本机localStorage。
- `fashmaker-prototype-products`：沿用既有商品库，新增source字段及稳定来源映射。
- 上传来源素材列表从已有导入商品的素材链接恢复；并非独立原文件存储服务。删除关联后当前Demo不会保证永久保留原文件。
- 来源与发布记录中的demo=true明确为演示；不采集账号、密码、AppSecret或真实店铺Token，不打开平台授权页，不调用平台读写接口。
- 同源不同页面重新打开可读取本机记录；不提供线上持久化、成员权限、凭证服务、自动定时同步、真实网络失败恢复或多终端云同步。
- 使用HTTP本地服务器打开页面可共享数据；不同端口、域名或file协议的存储空间可能不同。

## 6. 当前验收

1. 全站侧栏可进入店铺管理，窄屏也可进入，当前页正确高亮。
2. 两家店独立连接/断开、导入同名商品互不合并；重复同步不重复建商品。
3. 从店铺管理导入后能跳转商品库，来源筛选与商品详情来源一致。
4. 来源图片标为上传素材，生成结果仍通过productId关联。
5. 保存本地标题后模拟店铺修改，冲突不覆盖；两种取值可处理，有冲突时回写被拦截。
6. 缺少物流、价格或库存不合法、未选择主图详情图时阻止预览；未勾确认阻止提交。
7. 原商品更新保留itemId；新品通过后保存新映射；发布历史保持完整提交快照。
8. 刷新页面记录保留；断开不删除商品，重连恢复；发布状态与当前可售演示不混淆为真实结果。
9. 390px窄屏无横向页面溢出，键盘可操作原生dialog，嵌套弹窗Escape不关闭背后商品详情。

完整默认值及枚举见[字段契约](developer-field-contract.md)。本功能没有新增「用户素材+后台提示词」生成逻辑，因此无需新增生成提示词文件。
