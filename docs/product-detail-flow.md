# 商品详情页流程（2026-11-11）

## 入口与页面
商品库卡片、列表点击均直接进入 `product-detail.html?tab=products&product=<稳定ID>`，不再打开详情抽屉。旧资产库商品深链会转入新页。详情页复用资产库脚本及现有素材上传、结果关联、来源差异和发布模块；HTML 外壳来自资产库，修改共同结构时需同步两份 HTML。商品不存在时展示返回入口。

## 保存与内容
顶部显示商品 ID、保存提示和最新发布状态；分区锚点直达基础信息、商品资料、规格 SKU、商品素材、店铺与发布、发布记录。底部固定返回、保存修改、保存并发布/更新原商品。保存留在当前页，不自动发布。有未保存输入时离开提示；来源区发布按钮要求先保存。仅使用浏览器本地存储。

公共信息包含原有标题、描述、USP、素材和 commerce 对象；完整字段、默认值与校验见 [字段字典](developer-field-contract.md)。保存允许价格库存未填；发布时补齐。SKU 可增删，至少一行。标题不能为空，SKU 名称不能为空，重复非空编码不允许；金额大于零最多两位小数，库存为非负整数。

## 发布
保存并发布后打开原有店铺发布面板，带入品牌、首 SKU 规格、售价、库存。面板编辑首 SKU；其余 SKU 在详情编辑，随提交快照保存；多 SKU 中的后续行发布前必须有编码、规格、售价、库存。目标店铺、类目、物流模板、图片角色继续在发布面板确认。类目与模板为示例，不是官方完整枚举；自由备注不替代平台动态必填属性。

流程：保存资料 → 连接检查/冲突检查 → 补齐店铺字段 → 校验 → 提交预览及确认 → 模拟待审核 → 手动模拟审核通过并上架/审核不通过。页面即时展示状态、店铺、平台商品 ID、操作类型、时间、失败原因及提交快照。未有记录显示未发布；来源已有关联不等于 FashMaker 已发布。公共资料不因发布面板临时调整而覆盖。

原店更新依旧锁定来源店铺和商品 ID。多 SKU 为提交快照演示，来源同步仍仅比较标题和描述，不演示真实平台多 SKU 库存同步。实际平台字段、SKU 限制与状态映射需正式接口联调。

## 验证
浏览器验证卡片跳转、品牌/SKU 保存刷新、发布字段带入、提交与审核后详情状态实时更新、390px 无横向溢出；无页面脚本错误。截图见 `qa/product-detail-desktop.png` 与 `qa/product-detail-mobile.png`。
